# Rink Photos

The About page gallery ("Rinks We've Served") loads photos from this folder.
Drop each rink's photo here using the **exact filename** below. The page checks
for the file at build/render time — when a file is present it shows the photo,
otherwise it shows a labeled placeholder panel (no broken image).

Order shown on the page, with expected filenames (any of `.jpg`, `.jpeg`,
`.png`, `.webp` works — the page tries each):

1. `jamestown` — Jamestown
2. `edge-ice-arena` — Edge Ice Arena
3. `apex-ice-arena` — Apex Ice Arena
4. `bremerton-ice-arena` — Bremerton Ice Arena
5. `tennity-ice-pavilion` — Tennity Ice Pavilion, Syracuse University

Example: `public/images/rinks/jamestown.jpg`

Recommended: landscape orientation, ~1600×1200 (4:3) or wider, optimized JP/WebP.
