# Images

All site pictures live here (logos, photos, graphics).

Files in this folder are served by Next.js from the site root, e.g.
`public/images/rink-reports-logo.svg` is available at `/images/rink-reports-logo.svg`:

```tsx
<Image src="/images/rink-reports-logo.svg" alt="Rink Reports" width={800} height={380} />
```
