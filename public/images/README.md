# Images

All site pictures live here (logos, photos, graphics).

Files in this folder are served by Next.js from the site root, e.g.
`public/images/rinkreports_logo.svg` is available at `/images/rinkreports_logo.svg`:

```tsx
<Image src="/images/rinkreports_logo.svg" alt="Rink Reports" width={740} height={380} />
```
